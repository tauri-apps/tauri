Added a `--packaged` flag to `tauri dev` on Windows, which launches the app with package identity through Microsoft's [`winapp` CLI](https://github.com/microsoft/winappCli) so APIs that require identity (notifications, share targets, app URI handlers, Windows App SDK) can be used during development. Requires `@microsoft/winappcli` and a `Package.appxmanifest` generated by `winapp init`.
