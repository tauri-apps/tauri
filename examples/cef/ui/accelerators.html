Chrome accelerators

This window was built with . Press the keystrokes below: the ones whose family this window kept behave the way they would in a browser, and the rest never reach Chromium's command controller at all.

  • Nothing here is a Tauri accelerator or a menu: these are Chromium's own, live because a Chrome style browser keeps its accelerator table even with no browser UI attached.
  • WebviewDispatch::print, go_back and go_forward keep working from Rust whether or not their family is allowed.
  • Console output of this window is reported to the main window's console panel, tagged with this window's label.
