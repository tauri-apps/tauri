CSP Android Fix Example

This example demonstrates the CSP (Content Security Policy) Android fix that resolves the issue where both script-src and script-src-attr directives cannot be used simultaneously on Android devices.

Problem Description

The original WRY Android implementation had a bug where simple string replacement would corrupt CSP headers:

Original CSP: "script-src 'self'; script-src-attr 'none'" Buggy Result: "script-src 'self' hash1 hash2-attr 'none'" ❌ BROKEN!

Solution

The fix uses regex to properly match and replace only the script-src directive:

Original CSP: "script-src 'self'; script-src-attr 'none'" Fixed Result: "script-src 'self' hash1 hash2; script-src-attr 'none'" ✅ CORRECT!

Implementation

To use this fix in your Tauri application, add the following to your web resource request handler:

use tauri_utils::csp_android_fix::apply_csp_fix_to_header; .on_web_resource_request(|request, response| { if request.uri().scheme_str() == Some("tauri") { if let Some(csp) = response.headers_mut().get_mut("Content-Security-Policy") { let hashes = vec!["'sha256-your-hash'".to_string()]; apply_csp_fix_to_header(csp, &hashes).unwrap(); } } })
